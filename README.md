# Market Compass

Dashboard pribadi untuk membandingkan IHSG, reksa dana pasar uang, USD/SGD/CHF myBCA dan emas HRTA Livin'.

- Snapshot riset: 22 Oktober 2026; horizon skenario: 22 Januari 2027.
- Semua data dan kalkulasi ada di `index.html`; dapat dibuka offline dengan browser.
- Tidak membutuhkan langganan ChatGPT, API key, atau backend.
- Harga tidak diperbarui otomatis. Spread HRTA 2% merupakan asumsi sampai kuotasi aktual diisi.
- Angka simulasi adalah skenario, bukan prediksi pasti atau jaminan hasil investasi.
- Isian dihitung di browser; perubahan simulasi kembali ke nilai awal setelah halaman dimuat ulang.

Penerbitan: GitHub Pages, branch `main`, folder `/`.
